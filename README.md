# scada-bridge-mcp

mcp-name: io.github.CSOAI-ORG/scada-bridge-mcp

Part of the **CSOAI Layer-0 legacy-bridge family** (sibling of `cobol-bridge-mcp`). Bridge industrial SCADA / Modbus / OPC-UA (OT) to ONE OS — parse, map, govern (IEC 62443 / NIS2).

**Tools:** parse_modbus · map_to_modern · govern_ot

```bash
pip install -e .
python server.py
```
